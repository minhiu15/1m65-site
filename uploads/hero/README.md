# Hero images

Đặt hai ảnh ở đầu trang vào thư mục này với tên:

- `hero-main.jpg` — ảnh móng chính, khung dọc `3:4` trên desktop.
- `hero-detail.jpg` — ảnh cận móng, được crop vào khung vuông `1:1` trên desktop.

Đường dẫn dùng trên website:

- `/uploads/hero/hero-main.jpg`
- `/uploads/hero/hero-detail.jpg`

Website có thể dùng trực tiếp JPG, PNG hoặc WebP. Ưu tiên hệ màu sRGB và dung lượng dưới 500 KB mỗi ảnh. Không đổi tên file sau khi đã gắn vào giao diện.
