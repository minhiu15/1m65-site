# Ảnh “Về chúng mình”

Đặt hai ảnh của section “Về chúng mình” trong thư mục này:

- `salon-corner.jpg` — ảnh góc tiệm.
- `nail-technician.jpg` — ảnh thợ nail.

Có thể dùng `.jpg`, `.jpeg`, `.png` hoặc `.webp`. Nếu dùng đuôi khác ví dụ trên, giữ tên phần đầu để dễ nối ảnh vào giao diện:

- `salon-corner.png`
- `nail-technician.png`

Không cần đổi kích thước trước; ảnh gốc chất lượng cao sẽ được xử lý khi đưa lên web.
