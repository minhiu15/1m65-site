# Font sources

Các font của trang admin được self-host từ kho chính thức
[Google Fonts](https://github.com/google/fonts) và dùng theo giấy phép
SIL Open Font License 1.1.

- Be Vietnam Pro: `ofl/bevietnampro`
- Lora: `ofl/lora`
- DM Mono: `ofl/dmmono`
- Great Vibes: `ofl/greatvibes`
- Quicksand: `ofl/quicksand` (3 file woff2 tiếng Việt, Latin, Latin mở rộng do Google Fonts tách sẵn)
- Nunito: `ofl/nunito` (3 file woff2 tiếng Việt, Latin, Latin mở rộng do Google Fonts tách sẵn)
- Baloo 2: `ofl/baloo2` (chữ trên vé xác nhận đặt lịch của V2; chỉ giữ 3 file woff2 tiếng Việt, Latin và Latin mở rộng do Google Fonts tách sẵn)

Font chỉ được tải từ cùng origin; Content Security Policy của trang admin không
cần cho phép Google Fonts hoặc domain bên ngoài.
